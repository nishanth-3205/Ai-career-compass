# 🚀 AI Career Compass

A Product Management case study that demonstrates how **Agile Scrum** and **Jira** can be used to plan, prioritize, and manage the development of an AI-powered career guidance platform.

---

## 📌 Project Overview

AI Career Compass helps students identify suitable career paths based on their skills, interests, and career goals. This project focuses on the **product management process** rather than software development, showcasing how a product is planned and managed using Agile practices.

---

## 🎯 Objectives

- Design and manage the product using Agile Scrum.
- Create and prioritize a Product Backlog.
- Plan and execute sprints using Jira.
- Track project progress through Scrum Boards.
- Deliver a structured Minimum Viable Product (MVP).
